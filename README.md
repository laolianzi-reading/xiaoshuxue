# 小数学 · 芜湖中考数学 145+ 提分工具

> 一款专为初中生打造的纯浏览器数学刷题工具，对标《实验班提优训练》《学霸》培优体系，覆盖人教版 7-9 年级全学段知识点。

## 在线访问

**👉 [https://laolianzi-reading.github.io/xiaoshuxue/](https://laolianzi-reading.github.io/xiaoshuxue/)**

无需下载、无需安装、无需注册，打开即用。

## 功能特色

### 📚 分层练习
- 覆盖人教版新课标 7-9 年级全部章节
- 基础巩固 → 提优拓展 → 难题拔高，三层难度精准匹配
- 智能抽题：薄弱知识点优先推送同类变式题，避免重复刷题
- 动态去重：同一轮练习内不重复出题，刷完一轮再循环

### 🎯 专题突破
- 按年级分类，每个专题 30-40 道精选题
- 涵盖动点问题、几何模型、分类讨论、新定义运算等中考高频难点
- 对标《学霸》拔高出题逻辑，针对性攻克压轴题

### ➗ 计算训练
- 7-9 年级分阶段计算题库，每阶段 100+ 道
- 每日计算任务：5 题一组（1 基础 + 2 提优 + 2 挑战）
- 连续全对自动提升难度，错题自动归入错题本

### 📋 套卷模考
- 分年级、分学期、分考试类型（单元/期中/期末/中考仿真）
- A 卷（常规统考难度）/ B 卷（培优拔高难度）
- 全真模拟考试计时，自动判分，错题自动归集

### ❌ 错题本 & 📊 学情报告
- 自动归集所有错题，标注知识点、错误原因
- 可视化薄弱知识点分析，精准定位提分空间
- 答题数据全程留存，追踪进步轨迹

### 👤 多用户 & 积分系统
- 支持多用户切换，各自数据独立隔离
- 每日签到、刷题奖励、模考积分，激励持续学习
- 数据本地存储，支持导入导出备份

## 技术特点

- **零依赖单文件**：一个 HTML 文件，双击即用，无需服务器
- **纯前端运行**：所有计算、判题、数据存储均在本地完成
- **隐私安全**：学习数据不上传云端，仅存储在浏览器本地
- **跨平台**：Mac / Windows / iPhone / iPad / Android 均可使用
- **离线可用**：加载后断网也能继续刷题

## 使用方法

1. 在线访问：[https://laolianzi-reading.github.io/xiaoshuxue/](https://laolianzi-reading.github.io/xiaoshuxue/)
